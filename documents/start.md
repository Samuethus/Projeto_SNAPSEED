
OBJETIVO 

Contrua um site chamado "index.html" com o layout modelo presente na pasta raiz do projeto. Demais arquivos seram usados para criação do menu de ajuste dos processo do projeto

DESCRIÇÃO
Será um painel de ajuste da qualidade de imagem facilitado, com um processo de anexar uma imagem, um menu lateral direita simplificado em tela unica sem necessidade deslizamento, previsualização em tempo real da imagem na esqueda/centro. 

PROCESSOS
Edição de imagem ; Recorte de image ; Girar imagem ; ajustes de qualidade ; configurar resolução ; configurar formato ; opções de salvamento

ESTILO
Dark premium ; blue royal

REGRAS DE TRABALHO
Commit e push serão automáticos ; após cada ajuste em arquivos, fazer commit e push para o repositório remoto (origin)
Sempre que ajustes em arquivos forem realizados, listar os arquivos alterados e apresentar link de redirecionamento para cada arquivo
